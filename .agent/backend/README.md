Use [Laravel REST API](../laravel/laravel-rest-api/SKILL.md) for endpoint implementation, [MySQL design](../database/mysql-design/SKILL.md) for persistence, [practical system design](../architecture/practical-system-design/SKILL.md) for cross-app decisions, and [API/payment security](../cybersecurity/api-payment-security/SKILL.md) for trust boundaries.
