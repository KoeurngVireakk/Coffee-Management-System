# Shared repository guidance

Read `AGENTS.md`, then `.agent/README.md` and the relevant skill. The canonical skill collection lives in `.agent/`; no Gemini extension, hooks, or automatic native skill registration are installed.

For phase development, read [the Gemini phase workflow](docs/project/gemini-phase-workflow.md). Without a new phase brief, follow its read-only onboarding and wait. With an explicit phase brief, apply the workflow within that scope; current user and host instructions govern authorization.
